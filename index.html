Claude Opus 5 추천. 멀티스텝 작업을 오래 붙잡고 있어야 하는 리팩토링, 대규모 코드베이스 탐색에 강점. 50만 토큰의 긴 컨텍스트가 필요하면 Grok 4.6도 대안.
일상적인 코딩 · 빠른 반복 작업
Claude Sonnet 5 또는 Gemini 3.7 Flash. 속도와 비용 대비 품질 균형이 필요하면 Flash, 코드 품질과 도구 활용력이 우선이면 Sonnet 5.
문서 · 사내 파일 연동 업무
구글 드라이브 자료를 자주 다룬다면 ChatGPT의 라이브러리 연동이 편리. 맥 사용자는 새로 나온 '컴퓨터 히스토리' 기능으로 작업 맥락을 자동 정리할 수도 있음.
초저지연 · 대량 배치 API 워크로드
GPT-5.6 Sol Ultrafast(프리뷰 대상) 또는 Gemini 3.7 Flash(공개 가격 $0.75/1M)가 속도·비용 면에서 유리.
영상 제작 · 여러 모델을 조합해 쓰고 싶을 때
Runway가 신규 'Media Router'로 자사·타사 모델을 자동 선택. 소재 기반 창작·세로형 콘텐츠는 Veo 3.1이 강점.
브랜드 이미지 · 다국어 텍스트가 들어간 이미지
고해상도·다국어 렌더링은 나노바나나 프로/2, 사실적 인물·질감 표현은 최신 Midjourney V8.2가 강세.
보컬이 들어간 음악 제작
다국어 보컬 품질이 필요하면 Google Lyria 3.5, 출처 신뢰성(워터마크)이 중요하면 Suno가 적합.
