복잡한 코딩 · 장시간 자율 에이전트 작업
Claude Opus 5 추천. 멀티스텝 작업을 오래 붙잡고 있어야 하는 리팩토링, 대규모 코드베이스 탐색에 강점.
일상적인 코딩 · 빠른 반복 작업
Claude Sonnet 5 또는 Gemini 3.7 Flash. 속도와 비용 대비 품질 균형이 필요하면 Flash, 코드 품질과 도구 활용력이 우선이면 Sonnet 5.
문서 · 사내 파일 연동 업무
구글 드라이브 자료를 자주 다룬다면 ChatGPT의 라이브러리 연동이 편리. 별도 업로드 없이 바로 참조 가능.
초저지연 · 대량 배치 API 워크로드
GPT-5.6 Sol Ultrafast(프리뷰 대상) 또는 Gemini 3.7 Flash(공개 가격 $0.75/1M)가 속도·비용 면에서 유리.
광고 없이 무료로 쓰고 싶을 때
챗GPT는 무료·Go 요금제에 광고가 시범 도입돼(한국 포함) 신경 쓰인다면 Claude·Gemini 무료 플랜이 아직은 대안. 광고 없이 쓰려면 챗GPT는 유료 플랜 필요.
영상 제작 · 캐릭터 일관성이 중요한 작업
Runway Gen-4.5가 벤치마크 1위. 소재 기반 창작·세로형 콘텐츠는 Veo 3.1이 강점.
브랜드 이미지 · 다국어 텍스트가 들어간 이미지
고해상도·다국어 렌더링은 나노바나나 프로, 사실적 인물·질감 표현은 Midjourney V7이 여전히 강세.
